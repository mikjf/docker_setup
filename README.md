#### -- Project Status: [Completed]

## Objective
Set up a FastAPI application with a PostgreSQL database using Docker and Docker Compose. Enable live development with automatic rebuilds using Compose Watch, and prepare for future CI/CD automation.

### Project structure
* `.dockerignore` – Files and directories excluded from Docker builds
* `.gitignore` – Files and directories excluded from Git version control
* `Dockerfile` – Instructions to containerize the Python app
* `compose.yaml` – Docker Compose file with FastAPI + Postgres + secrets + volume
* `app.py` – Main FastAPI application file
* `config.py` – App configuration (e.g., database connection)
* `requirements.txt` – Python dependencies
* `db/password.txt` – Secret file for the Postgres database password
* `README.Docker.md` – Auto-generated by `docker init`

### Technologies and packages
* Python 3.12
* FastAPI
* PostgreSQL
* Docker
* Docker Compose
* Compose Watch

### Setup instructions

#### Run Docker Init to generate project files
```bash
docker init

# Answer prompts:
# - Platform: Python
# - Python version: 3.11.4
# - Port: 8001
# - Run command: python3 -m uvicorn app:app --host=0.0.0.0 --port=8001
```

#### Add Postgres password secret
```bash
mkdir db
echo "mysecretpassword" > db/password.txt
```

#### Start the application with Docker Compose
```bash
docker compose up --build
```

#### Test the API
```bash
#POST a hero

curl -X 'POST' \
  'http://localhost:8001/heroes/' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "id": 1,
  "name": "my hero",
  "secret_name": "austing",
  "age": 12
}'

# GET all heroes

curl -X 'GET' \
  'http://localhost:8001/heroes/' \
  -H 'accept: application/json'
```

#### Enable live code reloading via Compose Watch
```bash
docker compose watch
```
